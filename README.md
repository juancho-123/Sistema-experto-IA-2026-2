# 🌱 Sistema Experto de Invernadero

Sistema experto desarrollado como proyecto académico para la gestión y toma de decisiones relacionadas con un invernadero.

## 📌 Descripción

Este proyecto implementa un sistema experto utilizando CLIPS y Python.

El repositorio contiene diferentes versiones de una interfaz gráfica desarrollada para interactuar con el sistema experto.

## 🧠 Tecnologías

- Python
- CLIPS
- Interfaz gráfica
- Sistema experto

## 📂 Archivos del proyecto

- `Invernadero.CLP` — Archivo principal del sistema experto desarrollado en CLIPS.
- `Invernadero_clipsy.py` — Versión de la interfaz gráfica.
- `Invernadero_clipsy_1.py` — Versión mejorada de la interfaz gráfica.

## 🎯 Objetivo

El objetivo del proyecto es desarrollar un sistema experto aplicado al contexto de un invernadero, utilizando reglas y lógica de decisión para representar el conocimiento del sistema.

## 🖥️ Interfaz gráfica

El proyecto cuenta con una interfaz gráfica desarrollada en Python.

Se incluyen dos versiones:

1. `Invernadero_clipsy.py` — interfaz gráfica inicial.
2. `Invernadero_clipsy_1.py` — interfaz gráfica mejorada.
